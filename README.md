# Stock Market App — Flutter/Dart

## Overview

Stock Market App is an academic mobile application project developed using Dart and Flutter.

The project explores the structure of a stock-market-oriented application, including multiple screens, reusable interface components, data models, and service classes.

## Technologies

- Dart
- Flutter

## Project Structure

The repository contains the following components:

| File | Purpose |
| --- | --- |
| `home_screen.dart` | Home screen |
| `login_screen.dart` | Login screen |
| `portfolio_screen.dart` | Portfolio screen |
| `stock_detail_screen.dart` | Stock detail screen |
| `news_screen.dart` | News screen |
| `pro_screen.dart` | Additional application screen |
| `stock_card.dart` | Reusable stock-related UI component |
| `stock_model.dart` | Stock data model |
| `api_service.dart` | API service component |
| `location_service.dart` | Location service component |
| `screenstate.dart` | Screen-related state component |
| `theme.dart` | Application theme definitions |

## Development Focus

This project was developed to practice:

- Organizing a Flutter application into separate files and components
- Building multiple application screens
- Working with Dart classes and data models
- Separating service-related code from interface components
- Structuring reusable UI elements

## Project Scope

This repository contains source code from a student development project. It is presented as an example of academic work with Dart and Flutter rather than a finished commercial application.

The repository currently contains individual Dart source files rather than a complete standard Flutter project structure. Additional Flutter project configuration and dependencies may be needed to build and run the application.
